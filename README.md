# Loja Virtual - Ekommart Style 🚀

Este é um projeto de e-commerce moderno construído com **Next.js 15**, **React 19**, **TypeScript** e **TailwindCSS**. O design é inspirado no estilo premium Ekommart, com foco em performance, estética vibrante e experiência do usuário impecável.

A **Fase 1 (Frontend & UI/UX)** foi finalizada com sucesso. Todas as páginas core, lógica de interface, gerenciamento de estado global para o carrinho e lista de desejos (wishlist) foram implementados com dados mockados de alta qualidade.

## ✨ Funcionalidades Implementadas

### 🛒 E-commerce Core
- **Home Page:** Carrosséis vibrantes, grids de produtos e banners promocionais.
- **Loja (Shop):** Grid de produtos com filtros funcionais por categoria e ordenação.
- **Detalhes do Produto:** Seleção de variações (tamanho/cor), galeria de imagens e reviews.
- **Carrinho de Compras:** Gerenciamento de itens, quantidades e cálculo de totais.
- **Wishlist:** Sistema de favoritos com persistência local e animações.
- **Busca:** Modal de tela cheia com filtragem dinâmica em tempo real.

### 👤 Área do Cliente
- **Dashboard:** Painel de visão geral para o usuário logado.
- **Pedidos:** Histórico de compras com detalhes de status.
- **Endereços:** Gestão de endereços com modal de edição dinâmico.
- **Detalhes da Conta:** Alteração de dados pessoais e senhas.

### 🏢 Institucional & Suporte
- **Quem Somos (About Us):** Página com história da marca e diferenciais.
- **FAQ:** Seção de perguntas frequentes com acordeões interativos.
- **Informações de Entrega:** Detalhamento de prazos e métodos de envio.
- **Contato:** Página com mapa, formulário e cartões de equipe.
- **404:** Página de erro personalizada com tema de construção.

## 🛠️ Stack Tecnológica
- **Framework:** Next.js 15 (App Router)
- **Linguagem:** TypeScript
- **Estilização:** TailwindCSS
- **Ícones:** Heroicons v2
- **Estado Global:** React Context API & LocalStorage

## 🚀 Como Executar

1. Clone o repositório
2. Instale as dependências: `npm install`
3. Inicie o servidor de desenvolvimento: `npm run dev`
4. Acesse `http://localhost:3000`
